# Division Facts From Tables

This stage teaches exact division facts as the reverse of known multiplication facts.

## Plain-Language Meaning

The learner uses facts such as `7 x 8 = 56` to answer `56 / 7 = 8` and `56 / 8 = 7`.

## Skills In This Stage

- `derive_division_facts_from_multiplication`
- `check_division_facts_with_multiplication`

## Secure Performance

The learner answers exact division facts from the `10 x 10` multiplication table and checks each answer by multiplying divisor and quotient.
