# Division Facts From Tables Lesson Note

This is the reference page for exact division facts from multiplication tables.

Division facts come from multiplication facts.

If you know:

```text
7 x 8 = 56
```

then you also know:

```text
56 / 7 = 8
56 / 8 = 7
```

Do not learn division as a separate random table. Learn the multiplication family and read the division facts from it.

## Zero and division

```text
0 / 2 = 0
0 / 7 = 0
0 / 10 = 0
```

Zero shared into equal non-zero groups gives zero in each group.

Never divide by zero.

## The full fact family

For `6`, `9`, and `54`, the family is:

```text
6 x 9 = 54
9 x 6 = 54
54 / 6 = 9
54 / 9 = 6
```

Multiplication builds the total. Division starts with the total and finds the missing group size or number of groups.

## Check by multiplying

Example: `72 / 8`

Think:

```text
8 x ? = 72
8 x 9 = 72
72 / 8 = 9
```

Check:

```text
9 x 8 = 72
```

## Daily division routine

1. Read the division family from this lesson note.
2. Say the multiplication fact that proves each division fact.
3. Cover the answers and write the division facts from memory.
4. Mix with older table families.
