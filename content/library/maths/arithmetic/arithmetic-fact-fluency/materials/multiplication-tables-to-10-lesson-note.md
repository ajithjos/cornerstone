# Multiplication Tables Through 10 Lesson Note

Multiplication means equal groups.

`4 x 6` means `4` groups of `6`.

```text
6 + 6 + 6 + 6 = 24
4 x 6 = 24
```

You can also see multiplication as an array: `4` rows with `6` in each row.

## The facts to know

Learn the facts from `0 x 0` through `10 x 10`.

The most important facts to make quick are:

- `2`, `5`, and `10` tables first
- `3` and `4` tables next
- `6`, `7`, `8`, and `9` tables with extra review

## Switching the factors

`4 x 6` and `6 x 4` have the same product.

The array turns, but the total does not change.

```text
4 x 6 = 24
6 x 4 = 24
```

This means one fact helps with the other order.

## Worked examples

### Example 1: `7 x 3`

`7` groups of `3`:

```text
3 + 3 + 3 + 3 + 3 + 3 + 3 = 21
7 x 3 = 21
```

### Example 2: `8 x 6`

If you know `6 x 8 = 48`, then you also know:

```text
8 x 6 = 48
```

### Example 3: `9 x 7`

Use the known fact:

```text
7 x 9 = 63
9 x 7 = 63
```

## Good learner self-talk

- `How many groups?`
- `How many in each group?`
- `Do I know the switched fact?`
- `Can I say the fact without counting every step?`

## Quick spoken practice

1. What does `5 x 7` mean?
2. If `6 x 8 = 48`, what is `8 x 6`?
3. Say the `7` table from `7 x 1` to `7 x 10`.
