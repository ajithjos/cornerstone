# Doubles And Add 10 Lesson Note

These are the next anchor facts to memorise exactly.

## Doubles to 20

- `1 + 1 = 2`
- `2 + 2 = 4`
- `3 + 3 = 6`
- `4 + 4 = 8`
- `5 + 5 = 10`
- `6 + 6 = 12`
- `7 + 7 = 14`
- `8 + 8 = 16`
- `9 + 9 = 18`
- `10 + 10 = 20`

## Add 10 facts

- `10 + 1 = 11`
- `10 + 2 = 12`
- `10 + 3 = 13`
- `10 + 4 = 14`
- `10 + 5 = 15`
- `10 + 6 = 16`
- `10 + 7 = 17`
- `10 + 8 = 18`
- `10 + 9 = 19`

## Why these matter

These are not just another list. They are anchors for later facts.

- `6 + 6 = 12` helps with `6 + 7`
- `10 + 8 = 18` helps when you make `10` first in a harder sum

## Worked examples

### Example 1: `8 + 8`

- This is a double.
- `8 + 8 = 16`

### Example 2: `10 + 7`

- This is an add-`10` fact.
- `10 + 7 = 17`

## Say this to yourself

- `Doubles are anchor facts.`
- `Ten plus a single digit is an anchor fact.`
- `Later I will use these to help with harder facts.`
