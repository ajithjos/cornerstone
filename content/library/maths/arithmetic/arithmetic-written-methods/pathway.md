# Arithmetic Written Methods

This pathway teaches the written arithmetic structure that sits on top of fact fluency.

It is for learners who now need to understand place value, column addition, column subtraction, written multiplication, and written division. For many learners, this is the pathway that turns arithmetic from a pile of separate tricks into one connected system.

Use this pathway alongside or after [Arithmetic Fact Fluency](../arithmetic-fact-fluency/pathway.md). Facts still matter here. The written methods become much easier when the fact layer is secure.

## Why This Pathway Exists

Many learners can copy a written method or finish a worksheet without really understanding what the digits are doing.

Typical problems look like this:

- digits are lined up by appearance instead of by place value
- exchange in addition or subtraction is memorised as a rule but cannot be explained
- multiplication and division methods feel random because equal groups and scaling are not clear enough
- larger calculations break down because the learner has not learned the repeatable paper algorithm
- the learner gets an answer but cannot tell whether it is sensible

The job of this pathway is to make the structure of arithmetic visible and usable.

## What Good Progress Looks Like

At the end of this route, the learner should be able to:

- read and build whole numbers by place value, including thousands
- align written addition and subtraction correctly and exchange when needed across any whole-number length
- explain why an exchange happened instead of only copying the step
- multiply whole numbers using short multiplication and long multiplication with partial products
- divide whole numbers using short division or long division, with remainders when needed
- check whether an answer is sensible before moving on

## Daily Delivery Shape

- session length: 12 to 18 minutes
- cadence: 4 sessions per week
- rhythm: one teach-and-model session, two practice sessions, and one check or review session

Meaning first still matters. If the learner cannot explain what the digits represent, stop and rebuild the idea instead of adding more pages.

The written algorithms in this pathway are for whole numbers. Fractions, decimals, negative results, and decimal division answers belong in later routes.

## The Route

### 1. [Place Value And Number Sense](./playlists/place-value-and-number-sense.md)

Start here for most seven-year-olds and for any older learner who still confuses digit value with place value.

What changes here:

- numbers stop looking like a string of separate digits
- the learner can talk about ones, tens, hundreds, thousands, and larger places clearly
- comparison and ordering become easier because the learner knows which digit matters first

### 2. [Written Addition And Subtraction](./playlists/written-addition-and-subtraction.md)

This stage turns place-value understanding into usable written methods.

What changes here:

- columns are aligned by place value instead of by spacing guesswork
- exchange becomes a meaningful trade, not a hidden ritual
- the same method scales from two-digit sums to thousands and beyond
- the learner can check an answer for reasonableness before moving on

### 3. [Written Multiplication](./playlists/written-multiplication.md)

This stage turns multiplication facts into short and long written multiplication.

What changes here:

- multiplication is treated as scaling, arrays, and partitioning
- one-digit multiplication is handled with a compact written method
- two-digit and larger multiplication is handled with place-value partial products

### 4. [Written Division](./playlists/written-division.md)

This stage turns division facts into short and long written division.

What changes here:

- division is treated as sharing and grouping with a remainder that means something
- one-digit divisors use short division when suitable
- multi-digit divisors use long division: divide, multiply, subtract, bring down
- the learner uses multiplication to check division

## Entry Guidance By Approximate Age

### Seven-Year-Old

Start at [Place Value And Number Sense](./playlists/place-value-and-number-sense.md).

Do not rush into formal written methods if hundreds, tens, and ones are still vague.

### Ten-Year-Old

Start with a quick baseline from [Written Addition And Subtraction](./playlists/written-addition-and-subtraction.md).

If written addition and subtraction are already solid, move into [Written Multiplication](./playlists/written-multiplication.md). If place value language is weak, route back to [Place Value And Number Sense](./playlists/place-value-and-number-sense.md) immediately.

## Exit Conditions

This pathway is doing its job when the learner can:

- explain place value through thousands and extend the pattern to larger whole numbers
- add and subtract whole numbers in columns with sensible exchange
- multiply whole numbers using place-value partial products
- divide whole numbers using short or long division, with a correct remainder when needed
- check work for reasonableness using the size of the numbers involved

This is not the end of all arithmetic. It is the point where the learner has a stable written-methods base to build on.
