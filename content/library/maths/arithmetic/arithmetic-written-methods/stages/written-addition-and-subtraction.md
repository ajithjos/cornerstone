# Column Addition And Subtraction

This stage teaches the learner to align digits by place value and use column addition and column subtraction for whole numbers.

## Plain-Language Meaning

Column methods are a clear way to organise place-value work on paper. They are not magic steps to memorise blindly.

## Skills In This Stage

- `add_whole_numbers_with_column_method`
- `subtract_whole_numbers_with_column_method`
- `explain_exchange_in_written_methods`

## Secure Performance

The learner can add and subtract whole numbers with any number of places, explain each exchange, and notice when an answer is not sensible.
