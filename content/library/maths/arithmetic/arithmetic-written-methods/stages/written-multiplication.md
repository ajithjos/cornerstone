# Written Multiplication

This stage teaches short multiplication and long multiplication as place-value methods.

## Plain-Language Meaning

The learner uses known multiplication facts, exchange, and partial products to multiply whole numbers on paper.

## Skills In This Stage

- `interpret_multiplication_as_arrays_and_scaling`
- `multiply_whole_numbers_with_written_methods`
- `estimate_and_check_products`

## Secure Performance

The learner can multiply whole numbers using a clear written method, keep partial products aligned by place value, and check that the answer is sensible.
