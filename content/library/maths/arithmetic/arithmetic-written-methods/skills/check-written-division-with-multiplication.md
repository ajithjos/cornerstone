# Check Written Division With Multiplication

- successful performance: checks written division using `divisor x quotient + remainder = dividend`, with the remainder smaller than the divisor
- likely mistakes: forgets to add the remainder back or accepts a check that does not recover the dividend
- out of scope: decimal division checks and proof notation
