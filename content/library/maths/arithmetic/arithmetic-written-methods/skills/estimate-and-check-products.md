# Estimate And Check Products

- successful performance: rounds or reasons about size to check whether a multiplication answer is plausible before accepting it
- likely mistakes: accepts a product with the wrong number of digits or never compares the answer with the size of the factors
- out of scope: formal error bounds and decimal estimation
