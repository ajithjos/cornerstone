# Read And Build Whole Numbers By Place Value

- successful performance: reads, writes, and builds whole numbers using ones, tens, hundreds, thousands, and larger place-value names
- likely mistakes: reads each digit separately, ignores zero placeholders, or loses the value of a digit when the number has more places
- out of scope: decimals, fractions, and negative numbers
