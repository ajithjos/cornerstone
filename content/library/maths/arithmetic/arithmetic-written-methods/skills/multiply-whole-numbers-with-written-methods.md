# Multiply Whole Numbers With Written Methods

- successful performance: multiplies whole numbers using short multiplication for one-digit multipliers and long multiplication with aligned partial products for multi-digit multipliers
- likely mistakes: ignores place value in the multiplier, omits the tens-place zero or offset in long multiplication, or loses carried values
- out of scope: decimal multiplication, fraction multiplication, and algebraic expansion
