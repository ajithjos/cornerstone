# Written Division Lesson Note

Division asks how many equal groups fit, or how much is in each equal share. In `84 / 4`, `84` is the **dividend**, `4` is the **divisor**, and the answer `21` is the **quotient**.

Unlike addition, subtraction, and short multiplication, written division works **from left to right**. Write each quotient digit above the place being divided.

Learn one example at a time. Use familiar multiplication facts to find each quotient digit.

## 1. Short division without an exchange

```text
     21
    ---
4 )  84
```

Eight tens shared into four groups gives two tens in each group. Four ones shared into four groups gives one one in each group. So `84 / 4 = 21`.

## 2. Short division with an exchange: 864 / 4

```text
     216
    ----
4 )  864
```

1. Hundreds: `8 / 4 = 2`. Write `2` above the hundreds digit.
2. Tens: `6 / 4 = 1` with `2` tens left. Write `1` above the tens digit.
3. Exchange the remaining `2` tens for `20` ones. Together with the original `4` ones, there are `24` ones.
4. Ones: `24 / 4 = 6`. Write `6` above the ones digit.

On paper, write the carried `2` small beside the next digit to remind yourself to divide `24`, not `4`. Check: `216 x 4 = 864`.

## 3. Keep a zero in the quotient: 816 / 4

```text
     204
    ----
4 )  816
```

Eight hundreds gives two hundreds in each group. One ten cannot give a whole ten to each of four groups, so write **zero tens** in the quotient. Exchange the ten for ten ones; `16 / 4 = 4` ones. The answer is `204`, not `24`.

## 4. A remainder at the end: 85 / 4

`8 tens / 4 = 2 tens`. Then `5 ones / 4 = 1 one` with one left. So `85 / 4 = 21 remainder 1`.

A final remainder must be nonnegative and smaller than the divisor. Check every division with:

```text
divisor x quotient + remainder = dividend
4 x 21 + 1 = 85
```

The remainder is what is left after making all the complete groups. We keep whole-number answers with remainders here; decimal answers come later.

## 5. Long division: 945 / 27

Long division writes out the multiplication and subtraction that short division keeps compact. Use it for a two-digit divisor or when you need to see each step.

```text
      35
     ---
27 ) 945
     81      <- 27 x 3 tens = 81 tens
     --
     135     <- 13 tens left; bring down 5 ones
     135     <- 27 x 5 = 135
     ---
       0
```

1. `27` does not fit into `9`, so use the first two digits, `94` tens. `27 x 3 = 81`; `27 x 4 = 108` is too much. Write `3` above the tens digit `4`.
2. Multiply: `27 x 3 = 81`. Subtract: `94 - 81 = 13` tens.
3. Bring down the `5` ones to make `135` ones.
4. Divide: `135 / 27 = 5`. Write `5` above the ones digit. Multiply and subtract: `135 - 135 = 0`.
5. The answer is `35`. Check: `27 x 35 = 945`.

Repeat **divide, multiply, subtract, bring down**. Do not bring down a digit before subtracting. After division has started, write a zero quotient digit whenever the current amount is smaller than the divisor, then bring down the next digit if there is one.

## 6. Long division with a remainder: 587 / 24

```text
      24
     ---
24 ) 587
     48
     --
     107
      96
     ---
      11
```

`58 / 24` gives `2`, leaving `10` tens. Bring down `7` to make `107`. Four groups of `24` make `96`, leaving `11`.

So `587 / 24 = 24 remainder 11`. Check: `24 x 24 + 11 = 587`, and `11 < 24`.

## Practise, explain, check

1. Solve `96 / 3`, then `96 / 4`. Which calculation needs an exchange?
2. Solve `824 / 4`. Keep every quotient place.
3. Solve `87 / 4` and check with multiplication and addition.
4. When ready for long division, solve `156 / 12`. Say the four steps as you write.
