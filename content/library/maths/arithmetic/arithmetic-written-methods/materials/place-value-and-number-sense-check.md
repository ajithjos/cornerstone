# Place Value And Number Sense Assessment

Keep this brisk and oral where possible.

1. What is the value of the `4` in `438`?
2. What is the value of the `4` in `40,812`?
3. Partition `6,502`.
4. Build a number with `7` thousands, `2` hundreds, `0` tens, and `5` ones.
5. Which is greater: `64,000` or `60,400`?
6. Which is smaller: `389,200` or `398,200`?
7. Put these in order from smallest to greatest: `4,500`, `4,050`, `5,400`.
8. What does the `0` mean in `20,507`?

Passing guide: 6 or more secure answers means the learner is ready for column addition and subtraction. If place-value language is still weak, repeat this playlist before moving on.
