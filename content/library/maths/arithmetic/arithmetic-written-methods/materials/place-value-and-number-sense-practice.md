# Place Value And Number Sense Practice

## Part A: Read and partition

1. Write `4,632` as thousands, hundreds, tens, and ones.
2. Write `58,020` as place-value parts.
3. What is the value of the `7` in `73,418`?
4. What is the value of the `2` in `620,405`?

## Part B: Build the number

5. Build a number with `3` thousands, `5` hundreds, `9` tens, and `1` one.
6. Build a number with `6` ten-thousands, `0` thousands, `4` hundreds, `0` tens, and `7` ones.
7. Build a number with `2` hundred-thousands, `8` thousands, `3` tens, and `5` ones.

## Part C: Compare and order

8. Which is greater: `4,180` or `4,810`?
9. Which is greater: `70,204` or `70,240`?
10. Order these from smallest to greatest: `3,506`, `3,650`, `3,056`.
11. Order these from greatest to smallest: `80,404`, `84,040`, `48,400`.

## Part D: Explain

12. Why is `50,030` greater than `50,003`?
13. Why is `609,000` greater than `96,000`?

Coach check: if the learner compares the last digit first, stop and return to the rule `compare the biggest place first`.
