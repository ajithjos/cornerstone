# Subtraction: two digits, no exchanging

Start with the ones. Subtract the bottom digit from the top digit. Move one place left and subtract again.

## Before starting

Understand place value and subtraction facts. Explain that one ten is ten ones. Practise one exchange before exchanging across zeros.

## Practise this level

Read the matching written-methods lesson note and work one example together first.
This activity generates nine fresh calculations at this level. In assisted practice,
check an exercise, read the explanation, and correct it before continuing. In an
assessment, work independently and submit the complete set for corrections.

You can also print a fresh set with working grids or a compact layout. Keep one
digit in each answer column and leave room above the numbers for exchanges.

This activity records practice at this level. It does not on its own confirm the
whole written-method skill across every number size.
