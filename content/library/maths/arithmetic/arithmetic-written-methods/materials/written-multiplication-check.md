# Written Multiplication Assessment

Do not help during the assessment except to read the question.

1. `36 x 7 =`
2. `428 x 5 =`
3. `48 x 23 =`
4. `307 x 42 =`
5. Write the partial products for `48 x 23`.
6. Why does the tens partial product start in the tens column?
7. Which answer is more sensible for `307 x 42`: about `1,300`, about `13,000`, or about `130,000`?
8. Explain one multiplication as equal groups, an array, or scaling.

Passing guide: 6 or more secure answers means the learner can move into written division. Keep multiplication facts in review if the written method is correct but slow.
