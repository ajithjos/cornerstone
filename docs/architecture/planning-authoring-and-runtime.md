# Planning authoring and runtime

The current delivery contract is [Teach, Learn, Practice and Checkpoint](./learning-product-definition.md).

Authoring uses explicit [playbook sections](../authoring/product-and-curriculum-model.md). Rust compiles these into [owner and learner delivery payloads](./delivery-workspace-contract.md), owns generation and scoring under the [practice quality contract](./practice-quality-contract.md), and launches separately packaged [interactive presentations](../authoring/activity-packages.md).

The schema is fresh-install only. There is no direct-material assignment path or parallel legacy session authoring model.
